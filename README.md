# Uteg

Dnevnik treninga za mobitel. Za svaku vježbu i svaku težinu pamti najveći broj ponavljanja.

- Vježbe i stupnjevi sprava: popis `EXERCISES` na vrhu skripte u `index.html`.
- Slike: `media/<id>.jpg` (početak), `media/<id>-2.jpg` (kraj), video `media/<id>.mp4`.
- Podaci se spremaju samo u pregledniku na mobitelu. Za sigurnosnu kopiju: Postavke → Preuzmi kopiju.

Slike vježbi: [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) (Unlicense, javno vlasništvo).
